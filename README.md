# AKG Quantum Quest

Premium real-estate marketing and buyer-advisory website for Bengaluru.

## Live site

https://akg-quantum-quest.github.io/akg-quantum-quest/

## Included

- Premium agency homepage
- Featured VMAKS Laurel project page
- Developer/project marketing services
- Buyer enquiry form
- Supabase lead capture
- WhatsApp call-to-action
- Mobile responsive navigation
- GitHub Pages compatible static site

## Supabase

The site uses the browser-safe Supabase publishable key to submit enquiries to `public.leads`. Do not add a Supabase service-role/secret key to this repository.

## Deployment

GitHub Pages is configured to publish the `main` branch from the repository root.

## Content note

Project prices, availability, approvals, RERA details, amenities and location timings should be verified against the current project documentation before advertising or booking.
